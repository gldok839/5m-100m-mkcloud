## 同样是专线，报价为什么能差好几倍？

带宽只是报价公式里的一个变量，下面这几项每一样都会拉开差距。

**计费方式。** 按流量和按带宽是两条路。流量起伏大、偶尔爆发的业务适合按流量计费，但单价通常更高；TK直播这类对速度敏感的，固定带宽更合适——带宽越大，费用越高。

**覆盖地区。** 跨境距离越远，建设和维护成本越高。美国、日韩、东南亚各有各的价，中东、非洲普遍更贵。

**节点数量。** 在新加坡、德国、美国各设一个接入点，每多一个节点多一笔钱；多条业务线共用时可以摊薄成本。

**增值服务。** 独立IP、专线优化、注册社媒账号用的独立线路，这些都单算钱。

**线路类型。** 这是最容易被忽略的一项。同样是50M，三种线路的年费能差出一倍以上：

| 线路类型 | 50M年费参考 | 特点 | 适合谁 |
| --- | --- | --- | --- |
| MPLS专线 | 18万-30万元 | 稳定性高、延迟低，成本高 | 金融、制造业等对网络质量要求高的企业 |
| IPLC专线 | 20万-32万元 | 点对点直连，安全性最高 | 处理敏感数据的金融机构、政府单位 |
| SD-WAN方案 | 12万-20万元 | 智能路由、部署灵活、成本低 | 预算有限、要多地区覆盖的成长型企业 |

这张表和前面的单价其实能互相验证：按电信香港方向300元/M/月，50M一个月1.5万元，一年正好18万——刚好落在MPLS区间的下限。两份不同来源的数据接得上，这些价格区间就值得参考。

## 下单前，这几条合同细节要问清

跨境专线超预算的地方，往往不在月租，而在报价单没写到的条款。

- **流量上限和超量费**：有些表面便宜的套餐设了流量上限，超出部分单独计费，月底账单可能让人意外。签之前把上限和超量单价问清楚。
- **带宽是独享还是共享**：同样叫5M，独享和共享在晚高峰是两种体验。
- **SLA写没写进合同**：可用性百分比、延迟、丢包率、故障响应时间，落在纸面上才算数。
- **固定IP怎么给**：跑跨境电商平台、做TK运营基本离不开固定IP，动态IP隔三差五变一次，平台就要重新验证一次。独立IP是包含在套餐里还是按240元/月这类价格另购，下单前确认。
- **合同期限**：运营商专线签约多年通常有折扣，幅度要谈；第三方方案以年付为主，续费价直接问顾问要个准数。

**100M专线能带多少台设备？**

看设备拿来干什么。日常办公——浏览网页、处理文档、收发邮件，每台设备只占几十到几百KB，100到200台同时用没问题；如果以视频为主，高清视频每台要吃5到10Mbps，大概只能撑10到20台同时在线；频繁传大文件、跑数据备份的场景，每台设备要几到几十Mbps，5到10台就到顶了。
